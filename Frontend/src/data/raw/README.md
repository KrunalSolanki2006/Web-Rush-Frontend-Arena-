# WebRush Life Receipts Dataset

Fictional, coherent dataset for the WebRush challenge "Your Life, In Receipts".
One person's digital life is represented from January–September 2025.

## Files
- life_receipts.csv — master receipt index
- places.csv — geolocated places
- music.csv — listening moments
- purchases.csv — purchases
- photos.csv — photos
- messages.csv — messages
- searches.csv — searches
- events.csv — events
- movies.csv — movies
- connections.csv — explicit cross-receipt relationships

The IDs are intentionally shared across files. `connections.csv` contains planted story relationships such as search→purchase, search→event, event→place, place→photo, and time/location/theme connections.

This is fictional demo data, not a Kaggle dataset.
